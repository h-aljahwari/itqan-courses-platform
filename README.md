# Itqan Courses Platform

## Overview

Itqan Courses Platform is a digital platform designed for managing courses, workshops, attendance tracking, surveys, participant evaluation, and analytics dashboards.

The platform supports digital transformation initiatives through smart forms, reporting systems, and modern user-focused experiences.

---

## Features

- Course Registration
- Workshop Management
- Attendance Tracking
- Pre & Post Surveys
- Analytics Dashboard
- QR Code Support
- Reporting System
- Arabic RTL Interface
- Government Branding Support

---

## Technologies Used

- ASP.NET Web Forms
- C#
- SQL Server
- Bootstrap RTL
- HTML / CSS
- JavaScript
